# Checkpoints

- [torch-checkpoint-convert-to-bf16](./torch-checkpoint-convert-to-bf16) - converts an existing fp32 torch checkpoint to bf16. If [safetensors](https://github.com/safetensors/safetensors) are found those are converted as well. It expects a Hugging Face-style checkpoint directory (`*.bin` weight shards plus `*json` config files and a `*model` tokenizer file, see [Sharded checkpoints: the Hugging Face layout](../../foundations/storage-and-data.md#sharded-checkpoints-the-hugging-face-layout)): `cd` into that directory and run `bash torch-checkpoint-convert-to-bf16`, and the bf16 copy is written to a `bf16` sub-directory. The `*.safetensors` files are regenerated from the converted `*.bin` files rather than converted in place. Should be easily adaptable to other similar use cases.

- [torch-checkpoint-shrink.py](./torch-checkpoint-shrink.py) - this script fixes checkpoints which for some reason stored tensors with storage larger than their view at the moment of saving. A PyTorch tensor is a view (shape, strides, offset) into an underlying storage buffer, and `torch.save` writes the whole storage, not just the part the view covers - so saving e.g. a slice `x[:10]` of a 1GB tensor writes the full 1GB to disk. It clones the current view and re-saves them with just the storage of the current view. Usage: `./torch-checkpoint-shrink.py --checkpoint_dir ./checkpoints/global_step10`, optionally with `--patterns 'layer*pt' 'zero*pt'` to only process matching files.
